# Ndeen Khaled — Portfolio Website

Responsive one-page portfolio starter in a warm brown/cream visual style.

## Included files
- `index.html` — page structure and content
- `style.css` — styling and responsive layout
- `script.js` — mobile navigation and footer year

## Preview
Extract the ZIP and open `index.html` in a browser. For best local development, use VS Code with Live Server.

## Publish to GitHub Pages
1. Open https://github.com/ndeenkhaled/ndeenkhaled.github.io
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (upload the files, not just the ZIP).
3. Commit to the `main` branch.
4. In Settings → Pages, select Deploy from a branch, `main`, and `/(root)`.
5. After deployment, visit https://ndeenkhaled.github.io

## Before publishing
- Replace abstract placeholder project visuals with your own project images.
- Add project detail pages or link cards to case studies as desired.
- Check that every description accurately reflects your contribution.
- Do not publish employer/client drawings, models or confidential information without permission. Use a self-created independent sample if permission is unavailable, and label it clearly.
- Confirm phone number and contact links.
- Remove any skill you cannot confidently discuss in an interview.
